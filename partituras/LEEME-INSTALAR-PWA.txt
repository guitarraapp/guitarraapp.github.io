EDITOR PDF DE PARTITURAS v11.0 - PAQUETE PWA
=============================================

Este ZIP contiene todos los archivos compilados listos para funcionar como
aplicacion web instalable (PWA) con soporte sin conexion en Android, iOS y PC.

CONTENIDO DEL PAQUETE:
- index.html y assets/      : Aplicacion web principal y estilos
- manifest.webmanifest      : Manifiesto PWA (nombre, colores, iconos)
- sw.js, workbox-*.js       : Service Worker para uso offline completo
- pwa-*.png, icon.svg       : Iconos adaptativos para pantalla de inicio
- partituras-editor-v11.html: Editor completo (tambien ejecutable en PC sin servidor)
- CONTINUIDAD.md            : Documentacion tecnica y hoja de ruta

COMO INSTALAR EN ANDROID / IPHONE / ESCRITORIO:
1. Sube TODO el contenido de esta carpeta (manteniendo index.html en la raiz)
   a cualquier alojamiento HTTPS gratuito como:
   - Netlify Drop (https://app.netlify.com/drop) -> arrastrar y soltar la carpeta
   - Cloudflare Pages / Vercel / GitHub Pages / Firebase Hosting
   Nota: por seguridad del navegador, los Service Workers (PWA) requieren HTTPS
   o http://localhost (no funcionan abriendo index.html con file://).
2. Abre la URL HTTPS resultante en Chrome (Android) o Safari (iPhone/iPad).
3. Pulsa "Instalar app" en la barra superior o "Anadir a pantalla de inicio".
4. Tras la primera carga con internet, tus partituras de la Biblioteca local
   (IndexedDB), el editor, el metronomo y los bucles funcionaran sin conexion.

COMO USAR EN PC EN LOCAL SIN SERVIDOR:
- Haz doble clic directamente sobre "partituras-editor-v11.html".
